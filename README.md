# Измерение скорости скачивания

Консольный скрипт для тестового задания «Это Легко». Принимает URL, делает
**10 последовательных GET-запросов**, полностью читает тело каждого ответа
и выводит среднее время запроса, общий объём данных и скорость скачивания.

## Запуск

Нужен **Python 3.9 или новее**. Используется только стандартная библиотека;
установка пакетов и виртуальное окружение не требуются.

Склонируйте репозиторий и запустите скрипт:

```bash
git clone https://github.com/iaspiridonov/internet-speed-test.git
cd internet-speed-test
python3 speed_test.py 'https://example.com/large-image.jpg'
```

Замените ссылку на прямой URL существующего файла. `example.com/large-image.jpg`
выше — пример формата, а не готовый ресурс. Можно передать другой тайм-аут:

```bash
python3 speed_test.py 'https://example.com/large-image.jpg' --timeout 60
python3 speed_test.py --help
```

`--timeout` — тайм-аут отдельной блокирующей сетевой операции в секундах,
по умолчанию 30. Это не ограничение на суммарное время скачивания файла.
URL с `&` и другими специальными символами следует заключать в кавычки.

Пример итогового вывода для десяти ответов размером 1 MiB, каждый по 0,1 с:

```text
Среднее время запроса: 0.100 с
Всего скачано: 10485760 байт (10.000 MiB)
Общее время запросов: 1.000 с
Скорость скачивания: 10.000 MiB/s
```

## Расчёт и единицы

- Время измеряется монотонным `time.perf_counter()` от начала запроса до
  полного чтения и закрытия ответа. Оно включает установку соединения,
  ожидание сервера, перенаправления и скачивание тела; печать в консоль
  в замер не входит.
- Среднее время = сумма времён десяти запросов / 10.
- Общий объём = сумма фактически прочитанных байтов тел всех десяти ответов.
- Скорость = общий объём / сумма времён запросов / 1 048 576.
- Единица скорости — **MiB/s (мебибайты в секунду)**: 1 MiB = 1 048 576 байт.
  Это байты, а не биты. Скорость считается по всему замеру, а не как среднее
  арифметическое скоростей отдельных запросов.

Тело читается блоками по 64 KiB и не сохраняется на диск. Память не растёт
пропорционально размеру файла. HTTP/HTTPS-перенаправления обрабатываются
стандартным `urllib`. TLS-сертификаты проверяются стандартными средствами Python.
При сетевой ошибке, HTTP-ошибке или неполном ответе с `Content-Length` скрипт
останавливается с кодом 1, без итоговой скорости и повторных попыток.
Ошибочные аргументы дают код 2; Ctrl+C — 130; успешный замер — 0.

## Что именно измеряется

Это скорость загрузки **с выбранного сервера**, а не гарантированная пропускная
способность интернет-канала: результат зависит от размера файла, сервера,
маршрута, прокси и текущей нагрузки. Для полезного замера выбирайте достаточно
крупный файл и учитывайте, что он будет скачан десять раз.

Скрипт просит не использовать кэш (`Cache-Control: no-cache, no-store`), но
не может гарантировать поведение промежуточных серверов. Он также запрашивает
ответ без сжатия (`Accept-Encoding: identity`). Если сервер всё же сжимает
ответ, учитывается полученное сжатое тело. Заголовки HTTP, служебные данные
TLS/TCP и HTTP chunk framing в объём не входят.

## Проверка

Тесты поднимают локальный HTTP-сервер, внешняя сеть не нужна:

```bash
python3 -m unittest -v
```

Проверяются десять полных последовательных загрузок, ожидание медленного тела,
ответ без `Content-Length`, перенаправление, пустой ответ, HTTP-ошибка,
обрыв передачи, тайм-аут и некорректные аргументы.
